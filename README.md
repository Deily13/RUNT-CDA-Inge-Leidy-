# Gestor de Placas CDA

Este proyecto tiene como objetivo facilitar a los ingenieros del CDA la **consulta de clientes 
mediante las placas de sus vehículos**, permitiendo determinar y recordar al propietario cuándo 
corresponde realizar la **revisión técnico-mecánica**.

Actualmente, el sistema está diseñado para funcionar de manera **local**. Sin embargo, se contempla 
la posibilidad de escalarlo en el futuro hacia una **plataforma web**.

---

## ⚙️ Elementos técnicos

- **Lenguaje de programación:** Java
- **Frameworks:** Spring y Spring Boot
- **Base de datos:** PostgreSQL (relacional)
- **Arquitectura:** en capas (separación de responsabilidades)
- **Frontend:** aún en definición 
- **Pruebas unitarias:** Junit5, Mockito
- **Control de versionamiento:** Git
- **Diseño UI/UX:** https://www.figma.com/design/z9NIQPD31HiPT59ucgHeq5/Untitled?node-id=0-1&t=XSn2d8Ii11mWzMWj-1

- ## Instalación
1. Clonar el repositorio: `git clone <https://github.com/Deily13/RUNT-CDA-Inge-Leidy-.git>`
2. Configurar la base de datos en PostgreSQL.
3. Instalar dedpendencias
3. Configurar variables de entorno
3. Ejecutar la aplicación con Spring Boot: `mvn spring-boot:run`


- **Ejemplo de uso:** un caso práctico de consulta de placa y resultado esperado.
- **Configuración:** variables de entorno necesarias (ej. conexión a la base de datos).
